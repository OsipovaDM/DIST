# Распознавание и обезличивание ПДн

Комбинированная система для поиска и синонимического обезличивания персональных данных в русскоязычных текстах.

## Что делает

- **Распознаёт** 10 атрибутов ПДн: фамилия, имя, ИНН, паспорт, банковская карта, ОГРНИП, IP-адрес, e-mail, свидетельство о рождении, КЛАДР.
- **Обезличивает** найденные значения с сохранением структуры (домен e-mail, префикс ИНН, BIN карты) и морфологии (род, число, падеж для ФИО).
- **Гарантирует** идемпотентность (одинаковые сущности → одинаковые замены) и согласованность однокоренных форм (Иванов/Иванова/Ивановой → одна фамилия в разных падежах).

## Архитектура

- **BERT** (`DeepPavlov/rubert-base-cased`) — для распознавания ФИО на основе контекста.
- **Регулярные выражения + контрольные разряды** — для структурированных атрибутов (ИНН по ФНС, карта по Луну, ОГРНИП, паспорт по регионам).
- **pymorphy3 + Faker** — для морфологически корректной замены ФИО.

## Структура

```
config.py       — параметры, справочники, пути
recognize.py    — валидаторы, регулярки, BERT, predict
anonymize.py    — морфология, обфускаторы, anon
dataset.py      — загрузка и разметка factRuEval
training.py     — обучение BERT
evaluation.py   — Faker-тесты, метрики
main.py         — оркестратор и демонстрация
```

## Использование

### Режимы работы `main.py`

Управляются двумя флагами в `config.py`:

```python
# ========== РЕЖИМЫ РАБОТЫ main.py ==========
RETRAIN = False         # True → удалить модель и обучить заново
SKIP_TEST = False       # True → не считать метрики
```

| `RETRAIN` | `SKIP_TEST` | Что происходит |
|---|---|---|
| `False` | `False` | Обучить (если модели нет) → оценка → демонстрация |
| `True` | `False` | Удалить модель → обучить заново → оценка → демонстрация |
| `False` | `True` | Обучить (если нужно) → демонстрация (без метрик) |

## Запуск

```bash
python main.py
```

При первом запуске модель обучается на factRuEval (~17 минут на CPU) и сохраняется в `models/rubert_pii/`. При повторных — загружается готовая, если `RETRAIN=False`.

## Демонстрации в `main.py`

Демонстрации можно отключать (закомментировать):

```python
    # demo_recognition()                                       # демонстрация выявления ПДн
    # demo_pipeline()                                          # демонстрация выявления и обезличивания ПДн
    # obfuscated, entities = anonymize_text(DEMO_TEXT)         # формат вывода КР
```

## По ТЗ КР

Функция `anonymize_text` в `main.py` принимает текст и возвращает кортеж `(обезличенный текст, список сущностей)`:

```python
obfuscated, entities = anonymize_text(DEMO_TEXT)
print(f"\nВход:        {DEMO_TEXT!r}")
print(f"\nВыход:       {obfuscated!r}")
print(f"\nСущности:    {entities}")
```
